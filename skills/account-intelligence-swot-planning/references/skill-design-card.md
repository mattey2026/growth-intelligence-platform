# Skill Design Card — account-intelligence-swot-planning (v4.0, 24-item standard)

| Item | Detail |
|---|---|
| Skill name | account-intelligence-swot-planning |
| Business problem | Account plans are static, generic, and slow; risks and whitespace are missed |
| Persona | Strategic AMs, AEs, CSMs, executives |
| Trigger | "Account plan / SWOT / QBR / what changed / prioritize accounts" |
| Inputs | Account(s), mode, period, prior snapshot |
| Data sources | CRM, ERP, ITSM, customer success, CLM, email, files, web |
| Connectors / tools | whitespace, prioritizer, change_diff, propensity, ts_forecast |
| Context requirements | Offering catalogue, segments, ambition, weights |
| Analytics | Trend, variance, cohort vs peers, correlation, anomaly |
| Predictive | Churn, renewal, expansion, cross-sell/upsell, revenue at risk, displacement, attrition |
| Reasoning | Signals → patterns → risks → opportunities |
| Decision logic | SWOT anti-generic test; 9-dimension risk rules; prioritization |
| Recommendations | Growth, relationship, and risk strategies; 30/60/90 actions |
| Actions | Tasks, opportunities, drafts, plan documents |
| Approval | Every write and communication |
| Output | Brief, plan, review, deep dive, change report, portfolio |
| Evidence | ≥ 90% evidence coverage reported |
| Confidence | Per SWOT item and prediction |
| Error handling | Sparse data → gaps first |
| Security | Internal-only stance and risk content |
| Auditability | Snapshot + ledger |
| Baseline | Research and plan-preparation time; plan outcomes |
| Success metrics | −70% research; −50% prep; ≥ 90% evidence coverage |
| Test scenarios | Full plan; generic-SWOT refusal; sponsor loss |
| Failure modes | Generic content; invented potential |
