# Skill Design Card — account-intel-outreach (v3.0)

| # | Standard item | account-intel-outreach |
|---|---|---|
| 1 | Business problem | Prospecting is slow or generic |
| 2 | Target persona | SDRs, AEs, ABM |
| 3 | Data sources (canonical) | CRM, intent data, web |
| 4 | Required tools/plugins | CRM/marketing automation, intent provider, web |
| 5 | Inputs | Accounts, personas |
| 6 | Data preparation | Channel-conflict and opt-out check |
| 7 | Business logic | ICP fit; signal relevance |
| 8 | Analytics (descriptive/diagnostic) | Signal summary |
| 9 | Predictive analytics | Conversion propensity; emerging signals; growth potential |
| 10 | Reasoning | Hypothesis labelled as inference |
| 11 | Recommendations | Account and persona prioritization |
| 12 | Actions | Drafts only |
| 13 | Human approval points | All outreach |
| 14 | Outputs | Point of view and drafts |
| 15 | Success metrics | Reply rate; meetings per 100 accounts |
| 16 | Baseline | Current sequence rates |
| 17 | Accuracy requirements | Rate by decile |
| 18 | Security requirements | Consent law compliance |
| 19 | Failure modes | Hallucinated prospect facts |
| 20 | Test scenarios | Sourced point of view; fake-meeting refusal |

The full test prompts are in `evals/evals.json` in the source repository.
