## Opportunity created within 90 days

| Element | Detail |
|---|---|
| Prediction | Opportunity created within 90 days |
| Historical data | Past targeted accounts with outcome, 4 or more quarters |
| Real-time data | Intent, signals, firmographics, CRM relationship |
| Signals | ICP fit score, intent surge, signal count, prior opportunities, persona seniority |
| Horizon | 90 days |
| Confidence | Per standards §4 |
| Explainability | Top factors per account |
| Intervention | Prioritize and personalize |
| Outcome optimized | Pipeline per seller hour |
| Accuracy measure | AUC; meeting and opportunity rate by decile vs random or current targeting |
