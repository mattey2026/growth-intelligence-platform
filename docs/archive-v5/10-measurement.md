# 20. Measurement Framework (v5.0)

**Baseline → AI-assisted result → Delta → Business impact.** No impact is claimed without a defensible method.

| Dimension | Metric | Method |
|---|---|---|
| Time saved | Minutes per task (research, analysis, plan, review, briefing) | Time diaries and observation vs telemetry |
| Admin effort | Manual updates, systems or screens | Observation vs approved change sets and tool calls |
| Interaction reduction | Steps to a decision | Observation vs conversation turns |
| Accuracy | Error rate; classification accuracy (≥ 90% target on labelled risk cases) | Blind expert audit |
| Prediction accuracy | AUC, calibration, MAPE vs incumbent | Ledger |
| Recommendation quality | Acceptance; outcomes when accepted vs not | Ledger |
| Revenue and pipeline impact | Win rate, slip, pipeline created, expansion converted | Matched control teams or accounts, same period |
| Customer impact | GRR, NRR, churn, time to resolve service-driven risk | Matched control |
| Risk reduction | Lead time on risks; risks flagged before they materialize | Ledger vs historical |
| Adoption | Weekly active users, repeat use, watches defined, briefing actions | Telemetry |
| ROI | (Measured delta value − cost) ÷ cost | Control-based deltas only |

## Per-capability baselines (first 10)
| Capability | Baseline measure |
|---|---|
| Twin | Time to assemble account context; number of "surprises" in reviews |
| Orchestrator | Risk lead time and precision vs historical churn and expansion events |
| BI copilot | Analyst hours per "why" question; decision latency |
| Win/loss | Model AUC before and after adding learned features; win-rate change on adopted learnings (vs control) |
| Knowledge | Time to find the authoritative answer; wrong-version incidents |
| Opportunity discovery | Opportunities per account per quarter; conversion to pipeline vs control |
| Relationship | Executive coverage score; single-threaded share; win rate by coverage |
| Competitive | Detection lead time of competitor entry; competitive win rate |
| Pricing | Discount leakage; margin; approval rework; realized vs expected margin |
| Watch | Time from condition to action; false-fire rate |
