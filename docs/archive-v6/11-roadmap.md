# 11. Roadmap: AI Chatbot → AI Analyst → AI Business Advisor → AI Decision System → AI Business Operating System

| Stage | Capabilities | Status |
|---|---|---|
| AI Analyst | Data, KPIs, BI copilot, predictions | ✅ v4–v5 |
| AI Business Advisor | Context discovery, memory, delta, stateful watch, command center | ✅ v6 |
| AI Decision System | Decision memory ✅; decision-intelligence engine (options → trade-offs → approvals) | P1 next |
| AI Business OS | Scheduled refresh jobs; warehouse-backed memory; applied learning loop; graph features in models | P2–P3 |

## Next priorities
1. **decision-intelligence** skill, built on the decision memory.
2. **Consumer engines** for D2C/B2C: cohort retention, marketing mix / ROAS, basket analysis.
3. **Warehouse adapter** for memory (same schema).
4. **Measured token and cost metering** from actual usage data.
5. **Scheduled refresh**, using the product's scheduled tasks where available.
6. **Applied learning**: rule updates that are backtested before adoption.
